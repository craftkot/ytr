# Operator: Reality

Адаптивный наблюдатель для Minecraft Java 26.3 + Fabric.

**Текущая версия:** 0.5.0  
**Рабочая ветка:** operator-dev  
**Репозиторий:** https://github.com/craftkot/ytr

## Возможности 0.5.0

- Пассивное наблюдение мира первые 24 000 игровых тиков.
- Отдельная память игроков по UUID; офлайн-время не засчитывается.
- Запись маршрутов, дистанции, истории добычи и направлений.
- Ограниченная карта последних 4 096 выкопанных блоков на игрока.
- 3D-компоненты выкопанного объёма по соседству граней.
- Центр-линии по каждому уровню Y с последующим соединением в 3D-граф.
- Раздельное обнаружение шахт на разных высотах.
- Схлопывание вертикальных полос высотой до 3 блоков в обычный просвет тоннеля.
- Сохранение более высоких вертикальных проходов как вертикальных сегментов.
- Определение тупиков, развилок, циклов и изолированных участков.
- 3D-координаты узлов и концов основных сегментов.
- Фоновая проверка до 128 сохранённых ячеек за серверный тик, без загрузки выгруженных чанков.
- Удаление устаревших ячеек, если в ранее выкопанном месте снова появился блок.
- Атомарное сохранение профилей; схема памяти 3 сохранена.

## Как устроена 3D-карта

Каждый горизонтальный слой анализируется отдельно. Его карта прореживается алгоритмом Zhang–Suen, затем центры соседних слоёв соединяются с учётом высоты. Вертикальные полосы высотой до трёх блоков считаются обычной высотой тоннеля и объединяются в одну центральную точку. Более длинные непрерывные вертикальные полосы сохраняются как вертикальные сегменты.

Это **послойная 3D-реконструкция**, а не точный 3D medial-axis transform. В сложных камерах и пересечениях возможны приблизительные координаты и лишние/пропущенные ответвления. Синтетические тесты проверяют базовые топологии; реальные шахты требуют отдельного игрового тестирования.

## Ограничения карты и аудита

- Учитываются только подходящие блоки, сломанные после установки мода.
- Старые шахты и существующие воздушные полости не сканируются.
- Фоновый аудит проверяет только уже записанные ячейки и только в загруженных чанках.
- Аудит удаляет ячейку, если там снова появился непустой блок — независимо от того, кто или что его поставило.
- Новые пустоты от взрывов и других разрушений без события игрока автоматически не добавляются в карту.
- Выгруженные чанки не загружаются ради аудита.
- Автоматическое копание, установка блоков и перестройка мира выключены.

## Сборка

Требования: Minecraft Java 26.3, Java 25, Fabric Loader 0.20.1+, Fabric API 0.165.2+26.3 и Gradle 9.8.2.

    gradle clean test build

Запуск тестового клиента:

    gradle runClient

Готовые JAR-файлы появятся в build/libs/.

## Команды

    /operator status
    /operator profile
    /operator tunnels
    /operator network
    /operator network2d

- status — фаза наблюдения, число профилей, сохранённых ячеек и бюджет фонового аудита.
- profile — персональная статистика игрока.
- tunnels — 3D-компоненты выкопанного объёма.
- network — высотно-зависимый 3D-граф: тупики, развилки, вертикальные сегменты и циклы.
- network2d — прежняя горизонтальная проекция X/Z для сравнения.

Команды profile, tunnels, network и network2d нужно выполнять от имени игрока.

## Хранение

    <папка мира>/operator_reality/operator-memory.json

Схема 3 сохраняется: обновление с 0.4 не должно сбрасывать профили.

Перед тестированием на важном мире сделайте резервную копию.
