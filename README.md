# Operator: Reality

Адаптивный наблюдатель для Minecraft Java 26.3 + Fabric.

**Текущая версия:** 0.3.0  
**Рабочая ветка:** operator-dev  
**Репозиторий:** https://github.com/craftkot/ytr

## Что умеет 0.3.0

- Первые 24 000 игровых тиков мира — пассивное наблюдение.
- Отдельная память игроков по UUID; офлайн-время не засчитывается.
- Запись маршрутов и пройденной дистанции.
- Учёт добычи камня, руды и других блоков.
- Карта выкопанных блоков в виде 3D-координатных ячеек.
- Восстановление связных участков по соседству граней (6 направлений).
- Предварительная классификация участков: линейный тоннель, камера, неправильная форма или маленький участок; для крупнейшего участка выводятся координатные границы.
- Анализ отдельно для текущего измерения.
- Ограничение карты последними 4 096 ячейками на игрока.
- Атомарное сохранение памяти и миграция старых сохранений на схему 3.

**Важно:** карта строится только из подходящих блоков, сломанных игроком после установки мода. Оператор не сканирует уже существующие пустоты и старые шахты. Обычная установка блока игроком в записанную ячейку проверяется через один серверный тик и удаляется из карты, в том числе если блок поставил другой игрок. Взрывы, поршни, потоки жидкостей и изменения от других модов пока не отслеживаются, поэтому это приближённая карта проходов, а не абсолютная карта текущего воздуха. Изменение мира самим Оператором отключено.

## Сборка

Требования: Minecraft Java 26.3, Java 25, Fabric Loader 0.20.1+, Fabric API 0.165.2+26.3 и Gradle 9.8.2.

В корне проекта:

    gradle clean test build

Запуск тестового клиента:

    gradle runClient

Готовые JAR-файлы появятся в build/libs/.

## Команды

    /operator status
    /operator profile
    /operator tunnels

- status — фаза мирового наблюдения, число профилей и число сохранённых ячеек.
- profile — персональная статистика игрока.
- tunnels — анализ выкопанных ячеек в текущем измерении.

Команду tunnels нужно выполнять от имени игрока, поскольку она анализирует измерение, в котором тот находится.

## Где хранятся данные

    <папка мира>/operator_reality/operator-memory.json

Схема 3 добавляет ограниченную карту выкопанных ячеек. Старые сохранения 0.1/0.2 нормализуются при загрузке; существующие профили не должны сбрасываться.

## Тестирование модели без Minecraft

В PowerShell:

    New-Item -ItemType Directory -Force build/model-test | Out-Null
    javac -Xlint:all -Werror -d build/model-test src/main/java/ru/ehtid/operator/data/PlayerMemory.java src/main/java/ru/ehtid/operator/analysis/TunnelAnalyzer.java tools/OperatorModelSmokeTest.java
    java -ea -cp build/model-test OperatorModelSmokeTest

Полные JUnit-тесты запускаются через gradle test. GitHub Actions дополнительно запускает dedicated server, проверяет /operator status, сохранение мира и корректную остановку.

Перед тестированием на важном мире сделайте резервную копию.
