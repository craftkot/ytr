Operator: Reality 0.5.0

Implementation:
- Added height-aware 3D tunnel-network reconstruction from per-Y centerlines.
- Vertical bands up to 3 blocks high are treated as ordinary tunnel clearance.
- Taller continuous vertical runs are retained as vertical shafts.
- Added 3D graph connections, corridor segments, junction coordinates and 3D path-length estimates.
- /operator network uses the height-aware analyzer; /operator network2d retains the 0.4 horizontal projection.
- Added round-robin audit of up to 128 previously mapped cells per server tick.
- Audit only reads loaded chunks and never force-loads terrain.
- If a mapped cell is no longer air, it is removed from all player profiles.
- World memory schema remains 3; no migration is required for 0.4 saves.
- World mutation remains disabled.

Known limitations:
- 3D reconstruction is layer-wise: centerlines are computed per Y layer and linked afterward. It is not a full 3D medial-axis transform.
- Vertical bands of up to 3 blocks are collapsed as tunnel clearance; unusually tall rooms may be represented approximately.
- Only suitable blocks mined after installing the mod are mapped.
- Existing tunnels and air spaces are not scanned.
- Audit can invalidate filled mapped cells but does not discover new air cells created by explosions or other non-player destruction.
- Audit examines loaded chunks only; unloaded chunks are skipped without being loaded.
- Audit budget is 128 mapped cells per server tick across all player profiles.
- World mutation is intentionally disabled.
