Operator Reality 0.23.0 — autonomous tunnel fold prototype

Verification: CI pending on this branch at commit time; not yet validated.
Feature opt-in defaults off. One per player, after 24k world + 24k active ticks
and a READY TUNNEL_FOLD plan. Requires a valid mined cave corridor away from
players and other entities. Moves only one plain STONE to a neighboring AIR
above the walkway, using two existing WAL-guarded block changes.

Admin commands:
- /operator anomaly enable
- /operator anomaly disable
- /operator anomaly status
- /operator anomaly rollback
- /operator sandbox monitor

Unit coverage includes minimal fold apply and rollback, original house minimum,
invalid journal refusal, and mid-apply interrupted WAL recovery.
Existing dedicated Fabric and hard-crash relocation integration remain in CI.

Limits: This is not fully seamless, visually invisible, or autonomous house/biome
rewriting. No automatic rollback, no inventories, no modded blocks. Use only
disposable worlds and back them up. Hardware power loss is untested.
