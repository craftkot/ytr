New features:
- Read-only, bounded server-wide execution WAL scan across offline players.
- Every WAL is validated against the exact per-owner PREPARED journal and SHA-256.
- /operator sandbox monitor: gamemaster-only, works from RCON/console.
- Warn at startup when a cross-player transfer is unfinished or a journal is damaged.
- Refuse ALL new sandbox apply writes if any owner's execution WAL is unresolved,
  malformed, missing its PREPARED journal or inaccessible.
- Limit scan to 128 owners / 512 execution files; reject symlink/malformed paths.
- No automatic rollback or forced chunk loads.
- 8 additional JUnit tests for WAL corruption, offline owners, ownership and scan caps.
- Extended real Fabric unclean-crash integration with monitor assertions after
  cold restarts during APPLYING and ROLLING_BACK, and after ROLLED_BACK.

Required CI:
- gradle clean test build --no-daemon, Java 25 / Minecraft Java 26.3.
- Dedicated Fabric boot with RCON /operator status, persisted schemaVersion 8.
- Existing real-world graceful apply/rollback across server restarts.
- Cross-region partial APPLY/RESTORE crashes, flush-before-terminal-phase tests.
- New monitor check of abandoned WALs from the dedicated-server RCON console.
- Upload 0.22.0 compiled JAR and source ZIP.

Limits:
- Offline owner's rollback is not yet available through an administrator command.
- New transfers remain globally blocked until an existing interrupted operation
  is resolved; monitor never deletes, repairs or overwrites its file.
- WAL/Anvil multi-file atomicity, hardware power loss, mods and inventories
  remain unsupported. Use only disposable worlds for manual sandbox testing.
