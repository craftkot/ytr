Operator: Reality 0.4.0

Implementation status:
- Added TunnelNetworkAnalyzer with X/Z footprint projection.
- Added Zhang-Suen centerline thinning with a hard limit of 128 iterations.
- Added graph compression into corridor edges and topology nodes.
- Added dead-end, junction, isolated-area and loop detection.
- Added junction coordinates, approximate corridor segment endpoints and estimated centerline segment lengths.
- Added /operator network and retained /operator tunnels.
- Added 11 topology tests covering straight/thick corridors, T and four-way junctions, loops, disconnected areas, dimension separation, vertical projection and diagonal-only contact.
- Kept world mutation disabled.
- Existing world memory schema remains 3; no migration is required for 0.3 saves.

Known limitations:
- Network analysis uses horizontal X/Z projection; vertical layers collapse.
- Stacked tunnels may merge in the network graph.
- Centerline segment lengths are estimates after thinning, not exact block-path lengths.
- Only suitable blocks mined after installing the mod are mapped.
- Existing tunnels and air spaces are not scanned.
- Explosions, pistons, fluids, dispensers and other mods' block changes are not fully tracked.
- World mutation is intentionally disabled.
