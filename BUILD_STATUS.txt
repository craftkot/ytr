Implemented in 0.3.0:
- Bounded per-player map of 4,096 unique mined terrain voxels.
- Terrain material classification.
- Six-face connected-component analysis.
- Dimension-aware tunnel reconstruction.
- Preliminary linear/chamber/irregular/small area classification.
- Bounding coordinates for the largest component.
- /operator tunnels for the current dimension.
- Delayed block-use verification: if a player fills a recorded mined cell, the voxel is removed from all affected player profiles on the next server tick.
- Pending placement checks are capped at 256 and flushed before server shutdown.
- Schema migration from 2 to 3, preserving existing player profiles.
- Chronological voxel eviction order restored after JSON load.

Known limitations:
- Only suitable blocks mined by a player after installing 0.3 are mapped.
- Existing tunnels and air spaces are not scanned.
- Explosions, pistons, fluid flow, dispensers and block changes from other mods are not fully tracked.
- The map retains at most 4,096 most recently mined unique positions per player across dimensions.
- Geometry classes are heuristics, not a full skeleton or branch reconstruction.
- World mutation is intentionally disabled. Operator does not yet create, extend or alter tunnels.
