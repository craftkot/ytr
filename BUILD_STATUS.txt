Operator: Reality 0.3.0

Implementation status before CI:
- Added per-player bounded mined-terrain voxel map (4,096 unique positions).
- Added terrain material classification for stone/ore and selected natural terrain blocks.
- Added six-neighbour connected-component analysis.
- Added dimension-aware analysis, linear/chamber/irregular/small classifications.
- Added /operator tunnels for the current player's current dimension.
- Added mapped tunnel cell counts to status and profile.
- Migrated world save schema from 2 to 3; old profiles are normalized.
- Added ten TunnelAnalyzer test cases and PlayerMemory voxel persistence/bounds tests.
- Extended the dependency-free model smoke test to cover linear tunnel reconstruction.
- World mutation remains disabled.

Verification still required:
- Java 25 / Gradle 9.8.2 full build and JUnit suite.
- Dedicated Fabric server startup.
- RCON /operator status smoke test.
- World save schemaVersion 3 persistence.
- Artifact upload and inspection.

Known limitations:
- Only player-mined terrain blocks observed after installing 0.3 are mapped.
- Existing tunnels/air spaces are not scanned.
- Placed blocks, explosions and other mods' block changes are not removed from the mined-voxel map.
- The map retains at most 4,096 most recently mined unique cells per player.
- World mutations are not implemented.
