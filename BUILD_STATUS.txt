Operator Reality 0.15.0

Verification: PENDING final GitHub Actions build and dedicated server smoke test.
Previous verified baseline: 0.14.0, https://github.com/craftkot/ytr/actions/runs/42172443702

Current intended platform:
- Minecraft Java 26.3, Fabric Loader 0.20.1, Fabric API 0.165.2+26.3
- Java 25 / Gradle 9.8.2
- gradle clean test build --no-daemon
- Dedicated server startup, RCON /operator status, world-memory schema 8

New experimental capabilities:
- Manual /operator sandbox apply, sandbox rollback and sandbox status, OP permission level 2.
- Live Minecraft BlockState replacement with an explicit default-state allowlist (11 block IDs).
- Entire 128-cell source/target AABB limits; no BlockEntity NBT, fluid, multipart, special states, entities within the volume or unsafe neighboring blocks.
- Source/target BEFORE journals and player construction snapshot must still agree exactly with loaded world.
- Per-cell fsynced write-ahead intent and post-write acknowledgement in a separate durable execution ledger tied to journal checksum and player UUID.
- Rollback only with a previously created execution ledger, checked current world state and no conflicts or unloaded cells.
- Remap player construction-memory positions only after verified completion, no false placement or demolition counts.
- New tests for ledger phase transition, persistence across restart, integrity corruption and source identity, plus memory remapping and strict block palette.

SAFETY:
- This changes game blocks and is not a production-ready transaction engine.
- It is an explicitly invoked sandbox function for disposable worlds with backups.
- No automatic AI world chaos or move; no inventories, scheduled ticks, entity transfers, cross-chunk disk atomicity or comprehensive physics/restart guarantees.
- Live sandbox apply/rollback on a loaded game world is NOT covered by the existing RCON smoke test.
- GitHub Actions artifact-name labels may still show 0.14.0 due to a workflow-file update restriction; inspect actual build/libs JAR filenames to identify version 0.15.0.
