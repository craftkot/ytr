Operator Reality 0.17.0

Verification: PENDING GitHub Actions on exact source commit.
Previously verified release: 0.16.0, https://github.com/craftkot/ytr/actions/runs/42183885352
Build toolchain: Minecraft Java 26.3, Fabric API 0.165.2+26.3, Java 25, Gradle 9.8.2.

New required CI checks:
- gradle clean test build --no-daemon, including JUnit fault-injection tests.
- Dedicated Fabric server boot and /operator status over RCON.
- REAL Minecraft block-state relocation and rollback using the actual sandbox transaction engine.
- Three separate Fabric server JVM lifetimes sharing a disposable test world:
  phase1: 26-block shell transferred, 52 guarded block writes, COMMITTED WAL.
  phase2: source/destination chunks and WAL checked AFTER restart, rollback executed.
  phase3: original cells and ROLLED_BACK WAL checked AFTER another restart.
- Keep world-memory schemaVersion 8 and publish 0.17.0 JAR/source artifacts.

Server integration test security:
- Test-only command gated by -Doperator.reality.ciSmoke=true,
  in-world operator_reality/ci-smoke.allow marker, admin privileges and zero players.
- Runner requires GITHUB_ACTIONS=true and operates on the CI run/world directory.
- The fixture uses actual stone and air BlockStates only; no inventories/BlockEntities.
- Runs on two separate chunks and uses the same WAL storage as gameplay.

Not yet proven:
- Abrupt unclean process termination during setBlock or chunk saving.
- Multi-chunk disk atomicity, block entities, modded blocks, physics and redstone.
- Automatic AI-driven world changes or autonomous rollback are still disabled.
